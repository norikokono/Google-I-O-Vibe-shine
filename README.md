# 🌌 Project Exposure: Kinetic Particle Morph

A high-performance "Vibe Coded" interactive experience built for the **Gemini Large Number Challenge**. This project explores the intersection of fluid physics, typography, and cinematic transitions using the Canvas API.

## 🤝 The Collaboration
This project was co-created through a "Vibe Coding" session between **Gemini AI** and **I**. By combining human creative direction with AI-assisted physics optimization, we developed a seamless countdown-to-exposure sequence that pushes the boundaries of browser-based animation.

## 🚀 The Vision
The experience takes the user through a rhythmic countdown from **10 to 1**. Rather than static transitions, each number is composed of a dynamic particle mesh that mathematically reconfigures its structure to "morph" into the next numeral.

### Key Features:
- **Kinetic Morphing:** 2,500+ particles utilizing target-based interpolation for smooth, organic transitions.
- **The "Exposure" Phase:** Upon reaching the final count, the system triggers a high-velocity physics explosion, simulating a digital "overload" or light exposure.
- **DPR Scaling:** Optimized for Retina and 4K displays using `devicePixelRatio` scaling to ensure razor-sharp visuals on all devices.
- **Performance Optimized:** Uses an offscreen canvas sampling method to maintain a steady 60FPS even during complex reconfigurations.

## 🛠️ Technical Stack
- **Engine:** Vanilla JavaScript / HTML5 Canvas
- **Environment:** Developed in Google AI Studio
- **Deployment:** GitHub Pages
